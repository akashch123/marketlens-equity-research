MarketLens Levered Beta & CAPM add-on

Upload the file pages/5_Levered_Beta_CAPM.py to your existing GitHub repository, retaining the pages/ directory. Do not replace app.py.

Requires streamlit, pandas and numpy (already commonly present in MarketLens). The CSV regression tool accepts date,stock_price,market_price columns, with at least 21 valid price rows to generate 20 returns.

Inputs are illustrative. Peer figures are synthetic examples.
